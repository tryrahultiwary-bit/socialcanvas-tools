How to install

Up and running
in a minute.

1

Download

Click Download for Chrome above, then unzip the file.

2

Move the folder

Put it somewhere permanent, like Applications. Not Downloads.

3

Developer mode

Open chrome://extensions and switch on Developer mode, top right.

4

Load it

Click Load unpacked, pick the folder, then pin it from the puzzle icon.

One extra step for Video Downloader and transcripts

On a Mac, open Terminal and run the setup inside the extension's folder. It installs the free tools they use.

Video Downloader
cd ~/Applications/video-downloader && bash install.sh
Insta Controls transcripts (optional)
cd ~/Applications/insta-controls && ./install.sh

Questions.

Why aren't these on the Chrome Web Store?

Google doesn't allow YouTube downloaders there. Installing them yourself keeps all three free, with no review delays when something needs fixing.

Is it safe?

All the code is open source on GitHub, so anyone can read it. Nothing is sent anywhere: no account, no tracking, no analytics.

Does it work on Windows?

Ad Blocker and Insta Controls work in Chrome on any computer. Video Downloader and Insta Controls transcripts need a Mac.

Chrome shows a "Disable developer mode extensions" banner.

Just close it. The extension keeps working. Chrome shows it for anything installed with Load unpacked.

A YouTube download fails with "403 Forbidden".

Try again in a minute. If it keeps failing, update the downloader engine in Terminal with brew upgrade yt-dlp.

How do I update?

Download the new zip, replace the old folder with it, then click the reload icon on the extension in chrome://extensions.
